# 건축 법규 AI — 간단 버전

용인시 건축 관련 질문을 정리하고, 확인이 필요한 공식 법령 원문을 안내하는 한 화면짜리 AI 도우미입니다.

## 특징

- 로그인, 데이터베이스, 서버 없음
- Gemini API 키를 브라우저 탭에서만 사용하고 저장하지 않음
- 공식 법령 원문 링크를 답변과 함께 표시
- GitHub Pages로 자동 배포

## 사용 방법

1. [Google AI Studio](https://aistudio.google.com/app/apikey)에서 Gemini API 키를 만듭니다.
2. 배포된 사이트에서 키, 대상 지역·조건·질문을 입력합니다.
3. 결과는 참고용으로만 사용하고, 표시된 공식 원문 및 관할 행정기관을 통해 최종 확인합니다.

## 주의

이 프로젝트는 개인 학습 및 포트폴리오용입니다. 법률 자문, 허가 판단, 행정 처분을 대체하지 않습니다.

## 배포

`main` 브랜치에 반영되면 GitHub Actions가 GitHub Pages에 자동 배포합니다. 공개 GitHub Pages를 사용하려면 저장소도 공개 상태여야 합니다.
